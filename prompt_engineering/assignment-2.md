## 📂 3. Create a Testing Framework

**Objective:**
Develop a structured testing framework to evaluate and document the behavior of different prompt versions for a specific task (e.g., text generation, summarization, question answering, etc.).

**Instructions:**

1. Select any one prompt related to your project or task.
2. Create **multiple versions** of this prompt by modifying parameters such as tone, phrasing, model type, or temperature settings.
3. **Systematically test** each version using your chosen model (e.g., GPT-4, GPT-5, or others).
4. Record the behavior, performance, and output quality of each version in a **tabular format**, following the documentation structure defined in the repository.
5. Include observations or notes that highlight how changes in the prompt or configuration affect the model’s output.
